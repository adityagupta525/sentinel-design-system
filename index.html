Sentinel

The design system for Centricity WealthTech's chat-led assistant for advisors — and every screen it has. This file is here so that opening the folder lands somewhere useful.

Look at it → Every screen, every journey, all 94 component specifications. Nothing to install.

Building it? The source is next to this file, and it is not what you should open directly:

  • design-system/ — the system. index.js is the only public entry.
  • screens/ — every screen and journey, plus the one fixture they all read.
  • dist/ — the whole system as one file, every screen as one file.
  • docs/HANDOVER.md — install, import, the four rules.

The pages under design-system/pages/ and screens/ compile their JSX in the browser, so a source edit shows up on reload with no build step. That is also why double-clicking one does nothing useful — run npm run preview and open them over http, or read the built copies in site/.
