# RefusalTurn

Every refusal in this product has the same two parts, and this holds them: **what it will not do, and
what it can do instead, by name.**

Write the body in plain English — an advisor may read it aloud. Never "I cannot action that request".
Say what would happen, and what stands in the way.

The chips are not decoration. A refusal with no way forward is a dead end, and an advisor cannot work
around a dead end. Each chip is a route that exists; never "try again".

Reach for it for: an instruction that would move money, an amount over a ceiling, something in the
domain but outside this product, a sentence it could not follow, and a name that matches two clients.
