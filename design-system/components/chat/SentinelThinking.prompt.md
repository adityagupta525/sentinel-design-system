SentinelThinking — the wait state: a shimmering label and three 6px bronze dots pulsing on **opacity**, 1.2s, staggered 150ms. No bounce: a 6px dot hopping beside text reads as jitter.
```jsx
<SentinelThinking />
<SentinelThinking verb="Reading his Q3 statement…" />
```
`verb` replaces the "Sentinel" label and changes nothing else. It must name work actually being done and the source the answer will cite — a verb that does not match the provenance under the figure is worse than no verb.

For work that names real, ordered steps use ProgressTrace instead.
