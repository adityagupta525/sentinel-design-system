IconInfo — Lucide "info" at 1.5px stroke, 14px rendered. Only ever used inside `InfoDot`, beside a figure an advisor has to defend. It is the single exception to the text-before-a-glyph rule: ⓘ next to a number is a convention advisors already read, and the words it would otherwise need would crowd the figure it belongs to.
```jsx
<IconInfo />
```
Do not thicken the stroke or change the grid; recolour only within ink / bronze / muted / status-fg.
