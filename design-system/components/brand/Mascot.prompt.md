Mascot — the product's character as one token-drawn SVG; the 3D model's front view at any size.
```jsx
<Mascot size={168} tone="light" state="attentive" />
<Mascot size={18} />                         // the signature size — measure before relying on it
<Mascot state="working" />                   // eyes pulse on SentinelThinking's 1.2s rhythm
```
Head only. Three states and no more — a state is a claim about what the product is doing. Never
centre the eyes; never add a colour; never use an image of the model where this will do.
